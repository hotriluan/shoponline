Hướng dẫn tạo OAuth Client (4 bước)
  1. Vào Google Cloud Console và tạo một project.
  2. Bật Google Drive API cho project đó.
  3. Tạo OAuth consent screen loại External, thêm scope https://www.googleapis.com/auth/drive.file, rồi bấm Publish to production. Để ở chế độ Testing thì quyền hết hạn sau 7 ngày và Drive ngừng nhận bản sao lưu.
  4. Vào Credentials, tạo OAuth client ID loại TVs and Limited Input devices, rồi chép Client ID và Client Secret vào ô bên dưới (và vào kho bí mật của công ty).
